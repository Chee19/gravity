# Playbook: Tiny

One clear edit with nothing to decide. No run, no worktree, no project conf, no documents.

1. Make the change. Touch only what it needs.
2. Run the relevant check: the test, type check, lint or command that would fail if this edit were wrong. If nothing
   can check it, say so.
3. Report in two lines: what changed, and the command with its output. Tiny still has no "done" without output.

**Step up.** The moment a decision appears, or the edit outgrows one clear change, stop editing. State the step-up out
loud, go back to the router's Announce step with the larger playbook, and start a run. Anything already edited stays
in the checkout and gets said out loud, so the run can account for it.
